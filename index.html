Couleurs sur les LED

Envoie la mire, puis compare les rideaux à l'aperçu : de haut en bas rouge, orange, jaune, citron, vert, vert d'eau, cyan, azur, bleu, violet, magenta, rose, blanc, pêche, marron.

Si le rouge tire sur le rose ou le vert sur le turquoise → augmente la correction. Si les couleurs claires (pêche) deviennent trop vives → diminue-la.

L'app Surplife envoie des animations jusqu'à ~70 images. Au-delà, ça marche peut-être : à tester.
